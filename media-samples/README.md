# media-samples

Directory locale per file media di test. **Il contenuto è ignorato da git.**

Simula il Media Storage (montato read-only nei container). Organizzazione suggerita:

```text
media-samples/
├── movies/
├── series/
├── documentaries/
└── extras/
```

Fonti per sample pubblici (da scegliere nello spike S1): file di test con HEVC 10-bit HDR10/Dolby Vision, audio TrueHD/DTS-HD/E-AC3, più tracce audio, sottotitoli PGS e SRT.
